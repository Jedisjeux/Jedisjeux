On distingue quatre types d'éditions :

| Type | Nouveau jeu ? | Géré avec |
| --- | --- | --- |
| [Ré-édition](reprint/) | Non | Une variante du jeu |
| [Traduction](translation/) | Non | Une variante du jeu |
| [De la même série](same-collection/) | Oui | L'association « Collection » |
| [Extension](expansion/) | Oui | L'association « Expansion » |

Toutes ces actions partent de la liste des jeux de l'administration (menu **Catalogue › Jeux**).
